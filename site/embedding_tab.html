How to read this

Same space within a network. Mode k is one vector over all (image, site) pairs, so image i's coordinates at site l are (f1(i,l), …, fK(i,l)). Within one network, coordinates at different sites are directly comparable. The coupling sets how much they may differ between neighbouring sites.

Across networks nothing is shared by construction. Depth matching: fractional puts site l of L at l/(L−1). DTW warps each network's sites onto the reference's. Its cost is the subspace distance 1 − |QATQB|F2/K between the K-column spaces of two sites, which ignores rotations. Procrustes then fits one orthogonal K×K rotation per network, the same at every depth, so a network's own motion is untouched. The relative residual after the rotation measures how transferable the embeddings are; it is shown per network and per depth.

Baselines. PCA and UMAP are computed at each site separately (on the centred cosine activations), so nothing ties one site's coordinates to the next. They are chained along depth by Procrustes: each site is rotated onto the previous, already rotated, site. This is the usual way to animate independent embeddings. The through-depth modes need no chaining: one mode is one function over all sites.

SEBA sets through depth. SEBA (the sparse rotation used for the explorer's sets) is run once on the stacked low space: the constant eigenfunction plus the first r−1 modes, each a vector over all (site, image) pairs. Each of the r sparse vectors is a set of (site, image) pairs, so its support can grow, persist or shrink along depth. The modes enter unrescaled, since only then are they orthonormal. The construction's other slice-constant modes, which carry no image information, are left out. The chart counts hard labels, so a set's count can also fall because another set's vector wins at those images while its own support persists. Other networks run their own SEBA; their colours are matched to the reference by overlap (a display choice).

Scale. In "raw", sites holding little of the low space collapse to the centre (the bars over the slider show where the space lives). "Equal size at every site" rescales each site by one number, as the post-hoc set readout does.

In-between frames are linear interpolations between neighbouring sites, for the eye only. Mode signs and tied eigenvalues are arbitrary. With per-site scale, pooled PCA fixes the axes within ties. In raw scale the pooled spectrum is flat (the modes are orthonormal over all sites), so the raw modes are used. Procrustes removes the rest across networks.
